# Restful Booker API Testing

## Project Overview

This project focuses on manual functional and negative API testing of the Restful Booker API using Postman.

The objective was to validate API functionality, authentication, request/response behavior, input validation, and error handling.

## API Tested

Restful Booker API

## Tools Used

- Postman
- Microsoft Excel
- GitHub

## Testing Performed

- GET Testing
- POST Testing
- PUT Testing
- PATCH Testing
- DELETE Testing
- Authentication Testing
- Positive Testing
- Negative Testing
- Invalid Data Testing
- Response Validation

## Test Documentation

Detailed test cases and execution results are documented in the Excel test report.

The report includes:

- Test ID
- Test Scenario
- Test Data
- Expected Result
- Actual Result
- Status

## Bug Reports

Unexpected API behaviors and validation issues identified during testing are documented in the Excel report.
